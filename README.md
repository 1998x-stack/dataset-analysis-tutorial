# 📦 AI神经网络数据集分析与实战 · 从入门到精通

> 📘 28章 实战体系 · 交互式 HTML 课程

> **English TL;DR:** An all-Chinese 28-chapter hands-on course on working with **AI/datasets via the HuggingFace `datasets` library** — from the data ecosystem panorama, `datasets` quickstart, features/ClassLabel/Sequence, and the Arrow columnar backend, to formats & caching, splits/sampling, and the core transformations `map()` / `filter()` / streaming. Covers text/image/audio preprocessing, streaming & big-data (Xet backend, iterators), sharding for distributed training, versioning/reproducibility (fingerprints), pipeline performance & common pitfalls, quality assessment, and license/compliance. Tours the classic benchmarks (GLUE/SQuAD, ImageNet/COCO, LibriSpeech/CommonVoice/LAION, Planetoid/OGB/D4RL), EDA & visualization, custom dataset construction, pipeline automation, 2026 features (v5.0 Agent Traces, Json()/Iceberg) and frontier suites (MathNet, REAL-1.1, VT-Bench) — ending with an end-to-end Chinese legal-NER capstone.

## 📖 课程简介

本课程以 **HuggingFace `datasets` 库为主线**，系统训练 AI 数据集的加载、处理与构建能力：从数据集全景与 Arrow 后端、格式转换、缓存与 Split 切分，到核心的 `map()`/`filter()`/流式处理，再到文本/图像/音频预处理、分片与分布式训练、版本管理与可复现性、性能优化与踩坑排障、质量评估与许可证合规。随后巡览 NLP/CV/语音多模态/图与 RL 的经典数据集，覆盖 EDA 可视化、自定义数据集构建与自动化管道，最后简介 2026 新特性与前沿基准，以中文法律 NER 的端到端实战收束。
